This site collects tutorials and browser versions of the
[PaperPrototyping](https://github.com/Hannahathome/PaperPrototyping) tools: a toolbox for
designing foldable polyhedra, voxel blocks, haptic widgets and the data that drives them.

The web apps are **basic versions** that cover each tool's core functions. The full versions
are the Processing sketches in the PaperPrototyping repository; every tool links to its folder
there. Output is meant to be printed and cut on a vinyl cutter, so always print at
**actual size**.
