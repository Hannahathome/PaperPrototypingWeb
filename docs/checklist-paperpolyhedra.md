# Physical checklist: PaperPolyhedra

Run this before switching PaperPolyhedra to `available` in `src/data/tools.json`, and after
any change to `src/tools/paperpolyhedra/core/` or `src/lib/`. Do the
[calibration checklist](checklist-calibration.md) first on the same printer and cutter.

App: `/apps/paperpolyhedra/`. Print at **Actual size**; cut the `_calib_` file first.

## Shapes

For each: set it up, download, print, cut, fold, then tick.

### 1. Triangle prism: 3 sides, diameter 60, height 50, tab 15, flap 5, taper 5

- [ ] Net inside the cutting area (no orange note about it)
- [ ] Each panel's top and bottom edge measure 52.0 mm (±0.5) on the print
- [ ] Panel height measures 50.0 mm (±0.5)
- [ ] Strip closes with the hook tab; lids seat with all tabs tucked
- [ ] Folded height 50 mm (±1)

### 2. Hexagon prism: 6 sides, diameter 50, height 50, tab 10, flap 5, taper 5

- [ ] Panel edges 25.0 mm, panel height 50.0 mm (±0.5)
- [ ] Strip closes; lids seat
- [ ] Folded height 50 mm (±1)

### 3. Square frustum: 4 sides, top 25, bottom 45, height 50, tab 10, flap 5, taper 5

- [ ] The app notes the folded height (52.9 mm) and lists what is outside the cutting area, if anything
- [ ] Bottom panel edges 45.0 mm, top edges 25.0 mm (±0.5)
- [ ] Strip closes into a frustum; both lids seat
- [ ] Folded height about 52.9 mm (±1), as the app says, not 50

### 4. Images (any shape above)

- [ ] Strip image lands on the panels as in the sheet preview, continuous across folds
- [ ] With "Turn side images upside down", the image reads upright on the folded shape
- [ ] Lid image covers the whole lid
- [ ] Fill colour prints over images and covers panels and lids fully
